# H2终态判读与论文填表规则

2026-10-24，在本轮终态结果尚未纳入文稿时准备。此文件整理既有规则，**不是新实验合同、门槛修改或后续训练授权**。方法见[正文](MANUSCRIPT_PREPARATION.md)，精确配置及SHA见[SOURCE_INDEX.json](SOURCE_INDEX.json)。

## 1 先回答三个不同问题

1. **固定配方是否有用？** 查看完整D−N、D−U质量条件及D/N成本，不用单个AP改善替代全部条件。
2. **结果是否支持中心通路解释？** 以D−U为关键控制，并结合已有粗/最终中心摘要；D−N还包含采样改变与历史训练因素。机制描述与科学门槛分别报告。
3. **是否形成论文贡献？** 将具体路径约束与直接先例比较，再判断证据充分性。工程PASS、单seed质量PASS与原创性/投稿就绪不是同一结论。

## 3 可能结果分别能支持什么

|终态情况|可以写入的结论|不能据此写入的结论与处置边界|
|---|---|---|
|工程未闭合、身份或必要字段不完整|当前证据不足以完成固定实验判定|不能用部分结果补成PASS；保留STOP，禁止自动重试|
|D−N、D−U全部质量及成本条件通过，中心统计方向也一致|固定约束在本单seed development中通过筛选；条件性中心观测与假设相容|不等于因果机制、跨seed稳定或原创性成立；只进入后续审查，不自动扩seed|
|D优于U，但未通过相对N、其他保护或成本条件|可描述控制间差值，但整体固定配方仍未通过|不能把局部优于U改写为可替代基线；不自动换半径、加通路或重训|
|D相对N改善，但不优于U或未通过D−U条件|没有足够证据将改善归于删除直接中心项|不能把共同的固定采样/普通差分收益全部算作H2贡献；固定设计按原规则结束|
|全部质量及成本通过，但中心误差未相应改善或记录不足|检测收益与机制证据不一致或机制尚未知，二者分别报告|不补写“通过精化中心提高AP”；不临时筛GT/置信度直到叙事成立|
|中心摘要改善，但检测质量或保护失败|某个条件统计改善，与整体检测取舍同时存在|不能用几何统计替代AP或豁免负向结果|
|D劣于U或两者均退化|该固定训练配方未支持H2优势|不推广为所有局部差分/约束方法无效，也不自动启动新配方|

“中心统计方向一致”不是额外的数值PASS门槛。按冻结的均值、中位数、正零负计数和分母完整展示，若不同统计方向不一致就记录不一致，不在终态后选择最有利口径。

## 4 中心证据须保留的限定

- U/D各用自己的最终Hungarian匹配；样本由最终输出选择，不是两模型相同GT/query的配对干预。
- 报告实际配对数与缺失字段；没有记录GT身份或覆盖明细时标UNKNOWN，不自动补推理。不能仅由总配对数推出GT集合相同。
- 粗到细变化属于各臂已选配对的条件统计。跨臂均值差、AP差、目标内支持差不是互相可替换的证据。
- N没有粗中心记录就保持UNKNOWN；不将已有N最终框或每epoch checkpoint近似补成缺失观测。
- 终点中心变化即使与检测收益同向，也不证明P失败根因、训练中的梯度冲突或完整因果机制。

## 5 终态后的既定材料处理

本清单只说明现有授权收尾应如何进入文稿，不产生新模型执行：

1. 核对原attempt的闭合/退出、源commit、输入、e120 EMA绑定及累计成本。原历史N的STOP与缺CLOSED单列，不由本轮替它闭合。
2. 按白名单核六份评分JSON与必要引用SHA。COCO bridge和原主评价器分表，top600/top300分表，指标绝对值与pp差值清楚区分。
3. 填完整N/U/D指标及D−N、D−U、U−N；保留全部负向项。引用未舍入的原裁决，不重算AP或按显示值重新判线。
4. 填三臂同会话18次测速及成本比，保留暖机、边界与显存口径；不能用验收77秒替代正式推理测速。
5. 填U/D粗/最终中心摘要、匹配分母与UNKNOWN，依据上表写结果讨论。
6. 最后撰写摘要、贡献结论及局限。单seed通过也不直接写投稿就绪；新增重复验证、公开数据研究或消融需另行确定范围和预算。

精简材料留D盘，checkpoint、全量预测和逐query中心留服务器；本文不建立下载任务或持续轮询。
