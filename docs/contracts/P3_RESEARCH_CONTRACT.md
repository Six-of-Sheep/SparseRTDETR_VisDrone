# P3 Research Contract

- The target is additional coverage of small objects missed by a fixed
  baseline, under an identical evaluation contract.
- Gains may not be manufactured by duplicate predictions, threshold artifacts,
  or changed evaluation mathematics.
- The closed YOLO Sidecar Query plus shared-NMS route is not reused.
- Masking after dense computation is not real sparsity.
- A sparse claim must prove that Query, attention, FFN, or target operators
  were not executed for skipped work.
- Each experiment records actual operator counts, FLOPs, or kernel changes.
- Formal experiments require a clean Git commit identity.
- Runtime, artifact integrity, scientific interpretation, accuracy,
  sparsity, and speed are separate state dimensions.
- Failed run evidence is retained permanently.

No upstream RT-DETR implementation, baseline, training schedule, or model
selection is frozen by this contract.
