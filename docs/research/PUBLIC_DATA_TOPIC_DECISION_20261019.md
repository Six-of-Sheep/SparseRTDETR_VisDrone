# 公开数据条件下的单次整图检测：一页立项审查

2026-10-19。**决定：本轮不立项，保留研究候选0个，不安排试错训练。** 研究范围收窄为共同协议RT-DETRv2-R18的单次整图推理；原C只作已有高计算参照。没有证据表明换公开数据、换R18、增加seed就构成研究增量，也没有证明下述两种常规适配在R18上无效。

**验证条件。** 仅筛选AI-TOD（区分v1/v2）与UAVDT。条件首选AI-TOD-v2：极小目标与密度变化更能检验单次整图的匹配／查询资源问题。作者资料与DQ-DETR正文支持其公开基准定位，但v2原始划分与下载包、底层xView条款和父场景关系尚未完整认证，**不是数据准入PASS**。AI-TOD包含预裁切800×800单元；“整图一次”只能指一次处理一个发布图像，不能宣称原始大场景一次完成。UAVDT官网不可达，条款、类别／尺度、原划分和测试GT本轮未核实，不以惯用数字补齐。

|仅审查、未保留的方向|具体问题／最近依据|为什么不立项|
|---|---|---|
|训练期NWD几何匹配成本|微小框的IoU对像素偏差敏感；NWD正文§3–4已提出度量并验证分配／损失等用途|移植Hungarian成本只是明确的常规控制；没有证据说明本R18的主要损失来自该项，也没有区别于既有度量／分配方法的机制|
|受预算约束的密度引导query分配|稀疏与拥挤图像可能需要不同query；DQ-DETR正文§3、§4.4已有计数、增强、动态数量及位置选择|固定Q或更换检测器不构成实质差异；还与旧Q300选择／fullpool边界重叠，不能换名重开|

**未来验证类型只采用“各数据集分别训练”**，不安排VisDrone权重跨数据集迁移。复用R18基础设施与公共预训练来源，外部集合需独立数据头／初态和数据专属协议；不能从原e120接续冒充独立训练。VisDrone与AI-TOD类别、尺度桶、预算和忽略语义不同，AP分开报告，不合并、不直接排排行榜。官方train用于训练、val用于开发，test留待方法／对照／终点冻结后一次性评价；不为跟随已发表trainval配方而提前消耗val。

**开发／最终评价边界。** 548继续是反复使用的development；1602继续是历史使用未完全核实的补充集合，独立资格BLOCKED。外部test公开不等于未见：须先登记访问、训练／预训练成员及父场景关联；无法证明场景隔离时只能称官方划分评价。新下载时间、字节无交集、换seed均不证明新场景独立。

**欠缺及预算。** 欠缺的是可区分于NWD／DQ-DETR的具体方法依据和部署规则，不是再加一次常规评分。最少补读材料是NWD扩展期刊论文的方法／基准划分及补充材料；其正文当前被验证码阻断，准确入口见[来源表](PUBLIC_DATA_TOPIC_REVIEW_20261019.md)。取得它也不自动立项。两方向的否定条件、常规控制及成本单位已列在来源表；均非执行方案。本轮训练／forward／科学评分／GPU测速为0，未来实验预算未分配，无服务器接续。原C、全部失败配方、STOP和旧门槛保持。
