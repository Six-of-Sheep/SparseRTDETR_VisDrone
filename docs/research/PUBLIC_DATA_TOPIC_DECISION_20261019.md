# 公开数据条件下的单次整图检测：一页立项审查

2026-10-19，revision-002：已补读用户提供的ISPRS扩展版，详见[NWD正文补充审查](NWD_EXPANDED_REVIEW_20261019.md)。**决定：本轮不立项，保留研究候选0个，不安排试错训练。** 研究范围收窄为共同协议RT-DETRv2-R18的单次整图推理；原C只作已有高计算参照。没有证据表明换公开数据、换R18、增加seed就构成研究增量，也没有证明下述两种常规适配在R18上无效。

**验证条件。** 仅筛选AI-TOD（区分v1/v2）与UAVDT。条件首选AI-TOD-v2：极小目标与密度变化更能检验单次整图的匹配／查询资源问题。扩展版确认v2与v1共用28,036图并重新标注，底层来源包含VisDrone；并非天然源独立的外部集合。v2原包／划分、底层条款和父场景关系尚未完整认证，**不是数据准入PASS**。AI-TOD包含预裁切800×800单元；“整图一次”只能指一次处理一个发布图像，不能宣称原始大场景一次完成。UAVDT官网不可达，条款、类别／尺度、原划分和测试GT本轮未核实，不以惯用数字补齐。

|仅审查、未保留的方向|具体问题／最近依据|为什么不立项|
|---|---|---|
|训练期NWD几何匹配成本|微小框的IoU对像素偏差敏感；旧NWD已提出度量；扩展版§4–5进一步用每GT top-k的RKA解决正样本、尺度不平衡及补偿问题|扩展版进一步覆盖此前设想；移植Hungarian成本仍是常规控制。anchor结论不能直接归因R18一对一匹配，尚无本基线病因证据及实质不同机制|

**未来验证类型只采用“各数据集分别训练”**，不安排VisDrone权重跨数据集迁移。复用R18基础设施与公共预训练来源，外部集合需独立数据头／初态和数据专属协议；不能从原e120接续冒充独立训练。VisDrone与AI-TOD类别、尺度桶、预算和忽略语义不同，AP分开报告，不合并、不直接排排行榜。官方train用于训练、val用于开发，test留待方法／对照／终点冻结后一次性评价；不为跟随已发表trainval配方而提前消耗val。

**开发／最终评价边界。** 548继续是反复使用的development；1602继续是历史使用未完全核实的补充集合，独立资格BLOCKED。外部test公开不等于未见：须先登记访问、训练／预训练成员及父场景关联；无法证明场景隔离时只能称官方划分评价。新下载时间、字节无交集、换seed均不证明新场景独立。

**欠缺及预算。** 欠缺的是可区分于NWD／DQ-DETR的具体方法依据和部署规则，不是再加一次常规评分。扩展版方法／数据／实验正文已读，不再作为缺件。单独补充文件未取得；作者页无明确独立补充链接，代码入口连接关闭，不宣称补充材料全部读完。数据尚缺v2包／split／父图来源及许可、固定实现与完整评价配置；论文内752,745／752,754计数矛盾也须由具体官方包核验。上述缺口不改变当前0候选决定。两方向的否定条件、常规控制及成本单位已列在来源表；均非执行方案。本轮训练／forward／科学评分／GPU测速为0，未来实验预算未分配，无服务器接续。原C、全部失败配方、STOP和旧门槛保持。
