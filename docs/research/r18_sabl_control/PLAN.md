## 2. 唯一常规路径S：保留N，末端加SABL式空间定位

N指原共同协议RT-DETRv2-R18/Q300、3层decoder、单768×1344图。N参数20094584。特征取hybrid encoder输出给decoder的stride8、256通道memory对应二维场F8，位于decoder value projection之前；不能用backbone原始层、query复制或冻结特征替代。原attention、分类、中心/宽高粗框头和所有层间reference更新完整保留。

每个普通query产生原第三层粗框b=(cx,cy,w,h)。r=sg(b)，sg为detach；对应像素角点为((cx−w/2)W,(cy−h/2)H,(cx+w/2)W,(cy+h/2)H)。从F8对未放大的r做7×7 RoIAlign，spatial_scale=1/8，aligned=True，sampling_ratio=2。这里**RoI不扩大**；下述1.7倍仅用于桶坐标，与已审官方配置/编码器区分。RoIAlign的像素中心和边界规则按已固定torchvision实现，不能混用grid_sample的边界语义。CPU接线时需核非方形/贴边/域外样例及确定性反向；严格确定性环境若拒绝算子则工程STOP，不临时放宽规则。

S保留SABL定位分支：两层256→256的3×3卷积/ReLU；沿正交轴用归一化sigmoid注意力求和，得到水平/垂直一维特征；各一层长度3卷积/ReLU；转置卷积×2上采样到14位置，按左/右、上/下半轴拆分，每边7位置（右、下反向）。每位置共享Linear(256,1)桶logit及Linear(256,1)连续偏移。无类别FC、query融合、分布历史或新门控。

例如水平池化为

\[
A^x_{ij}=\frac{\sigma(a^x(R)_{ij})}{\sum_{j'}\sigma(a^x(R)_{ij'})},\qquad f^x_i=\sum_j A^x_{ij}R_{ij}.
\]

纵轴对称。注意力归一化分母不自行加epsilon；FP32内部计算与有限性检查，零分母/非有限STOP。定位分支FP32，原检测器按原BF16 forward/FP32 loss训练；这不是全模型纯FP32。局部特征是stride8中已经存在的信息，不能声称恢复新原图细节。

设r像素角点为(L,T,R,B)，扩展桶域以同中心、1.7w/1.7h构成(L_e,T_e,R_e,B_e)，Δx=(R_e−L_e)/14、Δy=(B_e−T_e)/14。k=0,…,6：

\[
x_{Lk}=L_e+(k+1/2)\Delta_x,\quad x_{Rk}=R_e-(k+1/2)\Delta_x,
\]
\[
y_{Tk}=T_e+(k+1/2)\Delta_y,\quad y_{Bk}=B_e-(k+1/2)\Delta_y.
\]

对各边s，k*=argmax a_sk（精确并列取较小k），推理边为s_hat=x_sk*−Δ_s d_sk*。偏移不硬限桶内。分类训练是官方sigmoid BCE；推理选桶与softmax的argmax一致。输出唯一四边框再转cxcywh，原类别score不变（跨不同训练模型的数值不保证相同）；不做桶置信度rescoring/NMS/GT选边。保留原排序、top600/300、预算后raw-ignore及不补位规则。

RoIAlign只读有效粗框，r的宽高非正或非有限为异常STOP。最终边有限但逆序/零面积时按原后处理的零面积规则剔除并记录数量，不交换边、回退粗框或按GT选择；非有限为异常。解码不另做图像裁边，沿用原N后处理的裁剪边界。以上推理适配区别于官方完整Faster R-CNN，不称完整SABL复现。

## 3. 监督与真实梯度路径

原N的Hungarian输入、代价、类别VFL、L1/GIoU、encoder/decoder aux及DN均保持。匹配仍对原普通query粗输出使用原matcher，各模型各自计算；不能把N缓存配对冻结进训练，也不改成精修后重新匹配。跨模型只能按图像/GT比较，不能按query编号配对。

新边界头只监督这些普通正匹配query，全部普通Q300在训练和推理均计算；不在进入分支前按GT/小目标挑query。未匹配不造边标签。原DN各层原损失照常；新头本次不为DN加边界损失，避免改变DN损失集合。raw-ignore继续只影响原未匹配负分类，不移除原正匹配。small仅供终点评价，不用于加权训练。

GT边g_s的偏移标签t_sk=(x_sk−g_s)/Δ_s。最近桶为BCE正类；距离小于1桶宽的其他邻桶不作负类。最近桶总监督偏移；第二近桶仅在|t|<1时监督，其余不监督。并列按(|t|,k)稳定排序。用BCE及SmoothL1(beta=0.1)，系数均1，沿已审SABL常规监督，不加入精修框L1/GIoU、蒸馏或质量损失。

每物理microbatch有M个普通正匹配，L_bucket=加权BCE总和/max(4M,1)，L_offset=加权SmoothL1总和/max(M,1)，空组为可微零；边/桶无效项权重0，不以有效桶数重归一化。分母参考官方定位分支的正RoI约定；原N各损失分母及累积×1/2保持。总loss=L_N+L_bucket+L_offset。此额外监督必须在必要控制中同样存在。

梯度：边界loss→边读出→轴向池化/卷积→RoI特征→F8→hybrid encoder/backbone。r、桶格点、标签、GT以及匹配索引detach；没有通过RoI坐标回到第三层粗框/其框头的新增梯度。原N损失仍更新全部原decoder/粗头；新边界loss不直接反传到q3或原框头。这是共享特征共同学习，不是“新损失沿所有框层反传”。argmax只在推理使用，不引入straight-through；训练不对解码选择反传。

移动左右边同时影响中心与尺寸：δcx=(δL+δR)/2、δw=δR−δL，纵向同理。可表达混合修正并不保证选对同一物体边界；遮挡、邻近目标、低分辨率混叠、搜索域外GT、独立选边逆序均为反例。均匀/常值局部特征也可能仅学位置先验，不能把非零梯度当收益。

## 4. 最简单的必要控制A：去空间排列，保留参数与监督

一个S方法，另设一个消融A，不是第二个研究候选：对同一RoI R，在任何可学习局部卷积之前取通道均值m_c=mean_ij R_cij，再铺回R^A_cij=m_c。其他代码、四边格点、参数/初态、正样本集合规则、损失/分母、优化器、更新数和推理行为全部与S一致。均值不是detach；梯度仍回F8。卷积边缘填充可产生固定位置模式，A保留这一先验，但看不到该RoI内部的实际空间排列。

|臂|可训练原N|新增头|输入|额外监督|解释|
|---|---|---|---|---|---|
|N24|全部|无|原N|无|同日程原N控制；历史N仅初始化/背景|
|S24|全部|同一个SABL式定位头|实际7×7 RoI|同桶/偏移监督|唯一常规局部空间控制|
|A24|全部|与S逐参数相同|RoI均值铺回|与S相同|排除“仅增加头/监督包即足够”的解释|

按2个3×3卷积、2个长度3卷积、2个1×1注意力、2个转置卷积、2个共享256→1线性、全带bias且无norm的登记结构，新增参数解析计数1837572；S/A总21932156，N20094584。未来CPU实例化必须逐项核对，不能以此解析值冒充实物验收。S/A逐参数初始化一致；pre/post卷积Kaiming normal(fan_in,ReLU)、up卷积Kaiming normal(fan_in)、注意力与桶Linear normal std=.01、offset Linear normal std=.001，bias全零；固定CPU RNG fork seed0，不扰动原N/DN输入RNG。此处显式固定隐含默认，是否逐项等于官方全部默认仍须CPU比对，不声称初始精修框等于N。

S−N检验整个常规精修包，S−A检验在相同参数和监督包下真实空间排列的额外价值。A−N不能再拆成参数效应/监督效应各自贡献；无需为此增加第四臂。梯度与学习轨迹不同是干预结果，不要求共有权重训练后相等。若S≈A，即使两者高于N，也不支持局部空间信息解释。

[SABL原文](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123490392.pdf) §3.1–3.2；[固定官方头](https://github.com/open-mmlab/mmdetection/blob/cfd5d3a985b0249de009b67d04f37263e11cdf3d/mmdet/models/roi_heads/bbox_heads/sabl_head.py)；[固定编码器](https://github.com/open-mmlab/mmdetection/blob/cfd5d3a985b0249de009b67d04f37263e11cdf3d/mmdet/models/task_modules/coders/bucketing_bbox_coder.py)。这里沿用其空间定位机制，同时显式登记R18普通匹配、stride8单层RoI、末端附加头及不重评分等适配；不把适配称新机制。完整版本、原证据与阅读范围见SOURCES.json。
