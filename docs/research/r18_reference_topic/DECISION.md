# 一页选题决定：更新参考框时保留边界分布的几何含义

2026-10-26｜**保留一个待验证问题，不认定新算法成立。** 原N的小目标有中等IoU但缺高IoU支持是动机；下述限制不能追认为N根因。PR24及P/H2/排序方向保持关闭。

|直接先例|有据机制与限制|假设及选择|
|---|---|---|
|[SABL](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123490392.pdf) §3.1–3.2|方向特征、分桶分类与连续偏移细化四边。官方实现沿轴加权求和再上采样，压缩一般不可逆；偏移未硬限于桶内，桶宽不是精度下限。|依赖RoI可辨识信息及可学习偏移。正交位置信息损失可能影响拥挤小目标，但无实证；未形成超出常规保留二维特征的干预，**不选**。|
|[D-FINE](https://arxiv.org/html/2410.13842v1#S4.SS1) §4.1式2–5|FDR以非均匀边分布及残差logits细化。各层分布固定相对初始框解码，注意力reference却会更新；越界GT编码到端点。初始框有监督，期望坐标连续，不能推导硬量化精度下限。|依赖初始参考与有限支持适合后续修正。修正远离初始边后，细密支持不随之移动，**可能**不利于精修；频率和影响未知。**保留此问题**。|

**已有方法→限制→改变。** 固定初始参考允许直接累加旧logits，却固定了细密支持的位置。拟改为参考上一层框，按实际边坐标迁移旧概率，再残差更新。各边独立；旧/新格点为x_n/y_k，相邻新格点线性分配矩阵为T：

$$
\widetilde p_k=\sum_nT_{kn}p_n,\qquad
p_l=\mathrm{softmax}(\log(\widetilde p+10^{-8})+\Delta z_l).
$$

T列和为1，左右边按实际坐标排序；域外质量落端点并单列。新参考及T坐标detach，概率路径保留梯度，GT在新坐标重新编码。拟检验的是**移动参考时保留几何对齐概率先验**的价值，不是插值算子原创；不建联合分布、不改attention采样范围或损失。峰值扩散、尾部截断、累积漂移均可能使其失败；完整先例唯一性未知。

**最近常规控制。** C0：固定初始参考的普通FDR；C1：同样更新参考，但从新logits独立重建分布的常规迭代回归。三者同输入/监督/共有初始化，不能只比N。若迁移不胜C1，则旧概率迁移无额外价值；若C0不差且未见假定困难，结束此题。

**最小下一步（另行授权）。** 先CPU核质量守恒、域内一阶矩、方向、截断和概率梯度，失败即止。通过后才审查冻结R18特征的轻量读出学习：稳定ID选train_core128图拟合、另64图探针，固定原N最终Hungarian配对；三层query/初始框共用，C0/C1/迁移各seed0、200更新、batch8，同FDR定位监督。初始化细节和系数执行前冻结；不加GO-LSD/LQE，不改分类/decoder。固定特征使新reference不影响后续attention，只检验读出可行性，不是完整D-FINE复现或e120收益。

**结果分支。** 仅初始/终点检验，报告分母、域外质量、配对边误差和IoU，不算AP/AR。探针匹配小GT不足100则证据不足，不扩图；迁移对任一控制的小GT配对IoU中位差≤0或平均归一化四边L1更差则结束。C1有效而迁移无额外价值，只支持常规更新；迁移胜两者也仅进入完整接线审查，类别集中效应不能外推。短学习阴性只关闭本探索配置，不证明所有实现无效。

**预算提案。** CPU 2线程/4GiB/5分钟；192图batch4共48次冻结检测器forward，三头共600次轻量更新及96次head-only检验forward；GPU阶段30分钟、wall60分钟、allocated18GiB、新材料512MiB、回传5MiB，异常STOP不重试。query原始FP32约169MiB，仅服务器留存。上限未经实测，不承诺耗时；不访问548/1602，不默认e120。

## 2026-10-27：CPU计算冻结及下一阶段规则（运行检查前确定）

本节及CPU_DEFINITION.json先于检查冻结；旧选题中的“同FDR监督”在此具体化为**FDR式定位读出控制**，不是完整D-FINE复现。检查代码为tools/r18_probability_transport_cpu.py；只执行构造张量算术，不构建网络或优化器。CPU检查通过不证明数据上的限制存在。

### 坐标、概率及层间路径

连续画布坐标统一采用归一化cx,cy,w,h；x向右、y向下，左右上下不混用。m=32、up=0.5、scale=4，a=3^(1/15)，W=[-4,1-a^15,...,1-a,0,a-1,...,a^15-1,4]共33点。格点为L=cx-w(1/2+W/4)、T=cy-h(1/2+W/4)、R=cx+w(1/2+W/4)、B=cy+h(1/2+W/4)。原生索引下L/T递减、R/B递增；T矩阵在实际坐标排序后计算，再映射回原索引。非均匀点间以实际距离插值。box及格点非有限、参考宽高非正、重复新坐标、概率非单位质量均拒绝，不宽松修复。

第一层从原N初始参考r0.detach()及z0得到p0=softmax(z0)，四边分别取实际坐标期望解码；若期望框宽高非正则STOP，不排序四边、不clip图像、不强制最小尺寸。后续M/C1以自己上一层预测框.detach()生成新格点，C0始终用r0.detach()。T只由旧/新detach坐标构成：域内点分到相邻两点，域外质量落最近端点，记录域外质量与signed一阶矩偏差；端点上的质量不计域外。T@p不另行归一化；输入p必须有限、非负且质量1。M使用固定epsilon=1e-8及log/softmax更新。解码不detach概率；下一层参考、T、GT目标及目标权重全部detach。T坐标无梯度，但M上一层概率和当前残差有梯度；C0旧logits也有梯度，C1无旧概率路径。每层定位监督直接作用于当层预测，aux不省略。原N特征/分类/匹配全部冻结，未来探针仅ordinary正匹配query、无DN，不声称覆盖完整检测器训练。

严格区分：T的列质量和、域内坐标一阶矩在实数算术成立；浮点检查绝对容差1e-10。相同格点T=I，但零残差M实际变成(p+epsilon)/(1+33epsilon)，一般并不等于p，期望也可能偏移。反向插值不是逆变换；多次迁移可扩散、丢失多峰，域外截断还会漂移。detach检查的有限差分固定参考/T，不能把重新计算参考引起的函数值变化误认为应有训练梯度。

### 三臂完整控制与剩余混杂

相同参数和零初始化消除了参数量及初始框偏置的解释，但旧概率路径同时改变跨层梯度与后续自身参考，三臂训练差异不能单独归因“携带了有用信息”。为限制解释：未来终点M的两次层间更新另做**局部均匀先验替换**，固定已算参考/T/残差，只将旧p替换为1/33，复用中间量，不再计算head、不向下层传播。与M自身局部输出配对比较，只检验当前先验信息；若不优于替换，不支持“旧概率的信息增益”，即使M胜C1也保留优化路径等解释。该替换不是第四个训练臂，也不是部署策略；CPU本轮不执行学习。
