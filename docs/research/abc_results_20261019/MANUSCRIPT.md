# 实验设置

本研究采用共同协议适配的RT-DETRv2-R18作为整图基线A。模型骨架固定于官方源码commit `1c8ac3f7ba84f14bd5651ab7b1b70d69a5f55f47`，但训练、数据和评价遵循本项目的共同协议，因而不将其称为完全未经修改的官方复现。输入画布为768×1344，训练物理batch8、累积2次，逻辑batch16；三个独立训练seed分别为0、1、2，各完成120轮、36,480次更新，并固定使用各自e120 EMA。初始化采用各seed独立未训练检测头和严格加载的ImageNet骨干；AdamW初始学习率1e−4、权重衰减1e−4，norm/BN参数不施加权重衰减，梯度裁剪0.1；2000更新warmup后余弦下降至1e−6。EMA衰减0.9999、warmup2000。保留共同协议原RandomIoUCrop等增强与末段停强增强规则，不依据评价结果选取最佳epoch。

同一seed的A/B/C共用同一权重。A为原整图候选；B为整图加固定类内hard NMS；C为整图与四个重叠局部切片合并后使用同一NMS。每个视图独立缩放到768×1344并只forward一次；四角切片尺寸为ceil(5H/9)×ceil(5W/9)，半开区间，边缘对齐原图四角。预测按裁剪原点平移回原图，不clip。每视图从300个query×10类的FP32概率中保留top600；按分数降序，再按view/query/category身份稳定排序。NMS仅抑制同类IoU严格大于0.5的后续框，几何计算使用原固定实现；最终取top600或其top300前缀，再执行原raw-ignore栅格过滤，过滤后不补位。位置选择、裁剪和合并不读取GT，GT仅用于既定过滤与评价。C是SAHI式常规适配，不是新检测器或SAHI原论文的逐项复现；裁剪提供位置、尺度及上下文不同的预测机会，不意味着创造新的原生图像细节。

评价分别在548图development和1602图“历史使用情况未完全核实的补充集合”进行。后者原manifest SHA为 `1af7eb4248be3097122d2168e18519c8db3ac11e17faff46aca8e3d78e5cfef4`，本项目机器证据支持其与实际4869训练成员的精确图像身份/内容SHA无交集，但不能证明近重复、飞行/地点或开发访问独立。两集合不合并，也不对AP进行跨集合加权平均。三个seed全部报告，两档预算全部报告；各自采用原主评价器和同输入raw-ignore的COCO桥接。主结论用top600 COCO AP/APS；AP75-small取同次COCO small/maxDets100的IoU0.75单元。top600/top300为外部候选预算，均不是COCO内部每图每类maxDets100的替代。原主评价器的pp单位不再乘100，与COCO0..1分数严格分列。

逐seed预冻结C−A条件为：主AP≥+0.30pp、APS≥+0.50pp、AP75-small≥−0.20pp、APM/APL各≥−0.50pp，次top300 AP/APS各≥−0.20pp。成本要求匹配硬件和batch下C/A≤6。所有绝对值、成对增量、均值与样本标准差以未舍入认证标量计算；样本SD的分母为n−1，只描述三个训练seed，不解释为置信区间或显著性。本轮成果整理没有模型调用、AP重算、bootstrap或新数据访问。

# 主要结果

在548图development主top600上，C相对A的AP成对提升均值为1.9540pp、样本SD为0.0209pp，三个seed的增量为1.9751、1.9536、1.9334pp；APS提升为2.5969±0.1971pp。常规NMS控制B相对A的AP提升为0.2641±0.0594pp，而C相对B仍有1.6899±0.0437pp的AP与2.3996±0.1597pp的APS提升。该比较支持在当前固定模型和协议中保留五视图方案的实用价值；它并不单独区分缩放、位置/上下文与多候选竞争的因果贡献。

在1602图补充集合主top600上，C相对A的AP提升为3.3207±0.0270pp，APS为4.4864±0.2271pp；最差seed增量分别为3.2902pp与4.2350pp。B−A的AP为0.2330±0.0383pp，C−B为3.0876±0.0566pp。两集合的各seed七项质量条件均通过；次top300的成对结果也按原规则完整保留，见[主表](MASTER.md)和[逐项表](PAIRED_ALL_PP.csv)。这只是两个既定集合各自的三seed结果，不能由补充集合更大的增量推断跨域泛化更强。

收益伴随明确取舍。development主top600的C−B APL在seed0/1分别下降0.4426/0.0045pp，seed2上升0.9578pp；均值+0.1702pp不能掩盖前两次下降。补充集合C−B APL三个seed均下降，分别为0.222843、0.001906、0.117745pp，均值−0.114165pp。C−A的AR-large在主top600也均下降：development为−3.614764/−2.107014/−4.685491pp，补充集合为−2.053266/−2.191422/−1.136082pp。次top300两集合均存在小幅正值的单seed，不能写成两档全部下降。另有B−A AP75-small在两集合主预算均下降，以及部分AR-medium/召回取舍。完整13项COCO指标和所有负差保留在CSV，图2专门展示两种大目标取舍。AP与AR是不同统计，不能由这些汇总指标认定分类、排序、定位或训练的唯一根因。

历史development固定64图端到端C/A为4.6725、4.7101、4.6656；补充执行期间在同一development固定64上复测为4.2918、4.8229、4.7801，全部低于6。计时包含真实整图、四切片forward、预处理、坐标回映射和NMS，未借缓存省略整图成本。两轮均为batch4/FP32和每臂两次暖机，成本流程同时产出两预算；并非两个集合各自全量吞吐或冷启动部署测量。补充链生产墙钟约4.52小时，包含串行CPU评分及I/O等待，不称为GPU忙时。实际reserved/allocated显存、每seed秒数及均值/SD单列于成本表，不把失败准备或未计量开发/传输写成零。

# 消融与失败对照

A/B/C构成保留的固定消融：B−A衡量所用常规NMS的集合内变化，C−B衡量在同一后处理下增加四个局部视图的净变化。它们保持模型权重一致，但C改变了视图数量、采样位置与缩放，因而不构成独立机制识别。失败候选均按当时冻结门槛保留，不能因后来的结果重新命名为成功。

固定Gaussian Soft-NMS用三个seed的原候选缓存进行12组双评价。D相对C的主AP仅提升0.077711/0.051245/0.101077pp，APS仅提升0.003406/0.025993/0.016951pp，未达额外收益要求，42条件中7项失败。固定配方关闭；其端到端GPU成本未测，不记成本FAIL或PASS，也不调σ重新筛选。

固定坐标投票同样采用三个seed原缓存。V-five相对C主AP下降0.418265/0.274447/0.469339pp，APL下降4.904372/4.218586/3.410952pp，42条件中21项失败；因此未进入条件GPU测速。它只否定该固定投票规则，不证明所有坐标融合不可行。

固定整图/切片混合微调只执行seed0双臂，各3648更新。T-slice/C相对T-control/C的AP/APS为+0.458543/+0.334749pp，但相对未微调原C为−0.142403/−0.375528pp，AP75-small下降0.734377pp；T-control自身也退化。28条件中9项失败，成本通过；相对退化控制的改善不能当作超越原C，单seed也不能冒称跨seed训练结论。

固定第六中心视图只完成seed0。center−C主AP/APS为+0.016496/+0.062040pp，APL为−0.829818pp；center−flip为−0.484965/−0.123526pp，14项质量中3项失败且同视图控制未超过，因而不执行seed1/2。center/A与flip/A成本均通过，但不抵消质量失败。flip保持控制，不能事后升级为主候选或宣称其单seedAP提升已被复验。其他旧MAL、边界探针、Moment/Full等关闭记录及原门槛继续保留，不借本轮重新启动。

# 局限性

首先，C是已有切片推理与NMS的常规适配，没有独立算法新颖性证据。development被多轮使用，报告的三个训练seed和小样本SD不足以覆盖模型、数据、场景及调试选择的不确定性。失败对照完整披露能减少选择性呈现，但不能消除反复开发集使用的偏差。

其次，1602图集合的历史模型开发使用仍未完全核实，用户对三项历史问题均回答无法确认；它只能支持披露该事实后的集合内补充比较，不能写成未见数据、独立确认或完全无泄漏。图像SHA及成员无交集也不代表感知近重复、相邻帧、飞行或地点完全独立。原独立确认资格维持BLOCKED，另列关联核查未执行，不通过更名或重新划分解除。

再次，补充评价显式使用 `supplemental-zero-gt-input-extension-v1`，不是声称旧输入接口完全不变。它只接纳两条精确认证的整数零高度GT：类别4经原raw-ignore后若保留仍计匹配分母；类别0保持原22像素忽略栅格与预测过滤。原文件、全部物理行、框和SHA不修改；未验证退化、小数、负尺寸、非有限值及身份/面积冲突仍拒绝，预测正几何保护不变。development不含这类输入且接口等价证据通过，不把该有限兼容性外推为所有退化标注通则。

最后，原主评价器依据固定官方源码审查及CPU转写，COCO桥接使用实际pycocotools，但未执行MATLAB/Octave官方运行时。当前成本仅覆盖固定64图、单硬件/批处理、暖缓存口径；大目标AP与召回存在上述取舍。若论文需要独立泛化、官方运行时等价、跨模型通用性或因果机制声明，需要另行有界协议与证据，不能由本次结果自动补足。本轮结束实验扩展，不默认进行下一训练。
