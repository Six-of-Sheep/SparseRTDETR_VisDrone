# H2三臂否定实验与GPU预算提案（未执行）

这是下一次审查用的设计，不是启动授权或生产就绪声明。本轮只有构造CPU原型；当前GPU执行预算为0。须先审查本方法差异与以下预算，之后另行授权生产实现/验收及真实GPU执行，不使用任何历史令牌、launch脚本或checkpoint续训。

## 1. 检验什么

检验：在相同局部采样与差分信息下，**去掉末层直接上下文中心残差**，是否比普通“局部差分＋上下文box头”更有利于小目标高IoU，同时不损害整体与中大目标。旧P的终点诊断只是设计约束，不是该假设的根因证据；也不要求H2增加框内支持比例。

|臂|第三层最细四点|最终中心残差|目的|
|---|---|---|---|
|N，同轮原生R18|原生学习offset|原bbox_head中心项f_c(q3)|必须重训的共同协议基线；历史B0只作成本依据|
|U，常规控制|预测reference内固定±w/4、±h/4四点|W_D[D_x;D_y]+f_c(q3)|已有PDC式局部差分加原中心头；与H2共享位置、样本和W_D|
|D，唯一H2候选|与U相同|W_D[D_x;D_y]，无bias/直接context中心项|只检验最后中心通路的约束|

三臂均单整图、Q300、3 decoder层、8 heads、每head总12点（4/4/4），前两层保持原生；第三层其余8点与联合attention权重机制沿用原生。D与U都不增加采样点或输入视图，不使用P的cell下限。固定四点在所有head上共享几何位置，可能降低空间多样性；D/U共同承担该变化。N与D比较含几何变化，只有D/U对照隔离直接context中心项；不能把前者单独当作路由效应。

## 2. 必须完成但本轮没有实现的接线

1. 显式新候选类型/配置，不放宽旧validator，不改任何旧release。第三层fine offset projection删除对应64个输出行；其余offset行保留原点序/初始化。四点位置与value采样只计算一次，给原context汇总和W_D共用，不能额外调用sampler冒充同成本。
2. N/U保留原bbox_head4维；D的第三层末个线性层只保留原width/height两行，中心改用W_D。原hidden层继续服务width/height。不保留未用的中心参数伪造参数量匹配。
3. W_D为2×512无bias、全零初始化，在CPU RNG fork内构造，随后各臂独立重置训练RNG。D/U共有初始tensor逐项相等；D比U少514个直接中心输出参数（2×256+2）。二者本来就不是参数完全相同的函数类，必须如实报告。
4. 原N的参数数引用已核20,094,584。按第三层删fine offset 64×257=16,448、加W_D 1,024、D额外删中心输出514，预估U=20,079,160、D=20,078,646；这些是结构账，**还没做完整detector构建核验**。不能宣称三臂等参数，更不能仅由参数更少宣称更快。
5. 采样reference原detach、final/aux输出reference原梯度角色、DN/普通query与native loss归一化、EMA整数buffer/anchors及保存恢复必须逐项验收。原型只覆盖叶层，不能代替GPU/BF16或完整训练链验证。

## 3. 数据、训练与终点

延续R18与公开VisDrone2019共同协议：现有认证train_core4869训练、548 development固定终点；不重新划分，不读1602，不把历史相关划分变成独立确认集。数据源、成员形成和公开复现材料的既有缺证保持。新独立公开数据/跨seed验证是未来单独决策，本提案没有额外数据集预算。

N/U/D各自从同一ImageNet backbone与seed0原生公共参数开始，新增/改变的参数严格登记；新optimizer、EMA=本臂初态且updates0、独立同seed RNG。每臂120轮×304=36,480更新，physical8×accumulation2、768×1344，BF16 forward/FP32 loss；原AdamW、lr1e−4/warmup2000/cosine到1e−6、clip0.1、EMA、e118弱增强时钟、Hungarian与VFL/L1/GIoU/ignore协议均不变。不使用本次CPU叶层状态、旧GPU验收state或旧e120作为训练初态。

只评价每臂固定e120 EMA；top600主、top300次、原主评价器与原COCO bridge。复用现有评分与比较实现，不用支持代理替代AP或选最佳epoch。没有中途AP、阈值/1/4系数扫描、追加P诊断、DN新探针或失败后重选候选。

## 4. 最小否定控制和结果解释

**最小必要控制是U。** 如果D对U没有高IoU收益，不能将N→D的变化归因于零差分中心约束：收益可能只是固定采样/普通PDC，H2特定解释不成立。D受到函数类限制，U可令f_c=0表达D；若U更好，则说明该限制至少在固定配方中无实用优势，不能靠“U自由度更大”解释掉失败。

为使“最终中心细化”也能被否定，未来固定e120推理的已有forward应保留第二层粗中心及第三层最终中心，不新增forward。在每模型最终300个query与训练有效GT的原Hungarian配对中，对raw area `0<area<=1024`的小GT，计算原图像素坐标下 \(e=\|c-c^*\|_2/\sqrt{area_{raw}}\)，报告粗/最终e的均值、中位数和最终减粗的正/零/负计数。每模型使用自己的固定最终配对，无置信筛选；配对数/零样本单列，不足记UNKNOWN，不当作AP评价总体。配对和分母沿用本次设计定义，不用它挑模型或改训练。若AP有变化而中心误差没有相应改善，不支持“中心细化”解释；即使两者同向，也不证明旧P根因或单独证明训练因果。该记录随新实验端点产生，不再对P取件/补采。

建议在未来执行前冻结以下**新提案筛选目标**。它们沿用原工程目标的量级，**不追溯改变固定P的门槛或裁决**；不是统计显著性或论文标准。

成本按同轮N/U/D、同一固定64 development图，FP32/batch4，**每模型2遍warmup，另6遍实测覆盖全部6个模型顺序排列**，实测中每模型在各位置恰好2次。报告18次实测、各臂均值/样本SD及allocated/reserved峰值。D/N端到端时间与peak allocated各≤1.05；同时报告U/N、D/U，不因参数/点数相同推断成本。时间口径包含预处理/H2D/forward/A式后处理/CUDA同步，仍不是batch1实时性证据。
