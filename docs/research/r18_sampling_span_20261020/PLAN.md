# R18单整图高IoU小目标：最细层采样范围下限

本轮决定：**保留一个机制明确、值得否定性验证的实用候选P**；不宣称原创算法或已有收益。B1是现成方法的常规控制，不是第二个创新候选。仅设计与合成CPU原型，尚无生产启动器和GPU授权。

DQ-DETR复现暂停，保留其本地提交241965d、STOP及未完成同步状态，不修环境、不恢复。原A/C保留；蒸馏、Soft-NMS、投票、切片微调及其他已关闭配方不重开。

## 1. 问题、证据与尚未证明的假设

问题不是“切片一定为何有效”，而是：**在不增加整图forward、query、采样点及参数量的条件下，给过小reference的最细层采样提供一个最小空间跨度，能否改善小目标AP75？**

|依据|支持什么|不能推出什么|
|共同协议A/C冻结development三seed主表：C−A AP75-small均值+2.502189pp，AR-large均值−3.469089pp|小目标高IoU与中大目标保护值得同时关注；C是高计算参照|不能证明A存在采样塌缩、切片提供新增原生细节，或本候选会有效|
|原生decoder四维reference分支，offset与reference宽高相乘|reference很小时，在有限offset下有效采样跨度会缩小|学习的offset无界，可能主动补偿；没有已保存分布证明训练后普遍不足|
|8像素正方形横移1/2像素，IoU分别7/9与6/10|小目标高IoU对定位误差敏感，这是几何事实|不是现有模型误差来源的诊断|
|已结束的续训契约审查未发现实现缺陷；T0也下降|必须用同轮配方基线，避免把续训重置混杂成方法效应|LR、EMA、增强重置均不是已确认掉点根因|

## 2. 唯一候选及最近常规控制

实际位置：`vendor/rtdetrv2_pytorch/src/zoo/rtdetr/rtdetrv2_decoder.py`的`MSDeformableAttention.forward`；3个decoder层均应用。原生固定8 heads、3层、Q300、stride8/16/32、每层级4点。原四维reference为归一化`r=(cx,cy,w,h)`，offset向量为`d_lmk`，点数`n_l`，原位置为：

```
s_lmk = (cx,cy) + 0.5 * (d_lmk / n_l) * (w,h)
```

P只改level0的采样宽高：

```
extent_0 = (max(w, 1/W0), max(h, 1/H0))
extent_1 = extent_2 = (w,h)
s_lmk = (cx,cy) + 0.5 * (d_lmk / n_l) * extent_l
```

`H0,W0`来自实际最细feature尺寸，固定768×1344对应96×168；不是原始图片或GT大小。一个单元是几何刻度选择，不扫系数。中心、query位置编码、回归reference、native detach和aux梯度路径不变；保留双线性/零填充/align_corners=False，不clip。DN和普通query同样处理。只要reference两轴均≥一个最细单元，采样与原实现完全相同；不能保证所有中大GT都不受影响，因为其预测reference也可能细长或偏小。

CPU原型先将`B,Q,1,4`reference按**12个采样点顺序**展开，再交给原生forward；不能误展开为3个level直接与12点相乘。没有添加网络参数、特征层、loss、教师或输入视图。实际训练后采样点数相同仍不保证相同耗时。

|臂|固定点数|修改|目的|
|---|---|---|---|
|B0，同轮基线，非历史B|4/4/4|原模型及训练|隔离任何训练/平台/实现差别，历史A不能替代|
|B1，常规控制|8/2/2|原生RT-DETRv2按尺度分配点数；总数仍12|判断是否普通的细层计算分配已足够|
|P，唯一候选|4/4/4|仅最细采样跨度一个单元下限|判断采样几何是否比常规点数分配有实用价值|

三臂均20,094,584可训练参数，CPU构建已核对。原生attention softmax覆盖全部12点，因此B1的最细层初始权重总量也从1/3变为2/3，这是原生点数分配的固有效应；它不是“逐层注意力质量不变、只改变点位置”的控制。B1保留原生8/2/2的径向bias和`num_points_scale`；它和B0仅这两项/层的初值不同，其余tensor逐项相同。P初始state全部与B0相同。构造替换层使用CPU RNG fork，之后三臂训练RNG独立重置同seed0。B1不是完整Box-DETR或其他模型复现，也没有声称所有差异仅一个标量。

## 4. 最小因果实验：三臂从头训练

选择**从头学习检测器，严格载入共同ImageNet backbone**，不使用原e120 EMA续训。原因是本候选改变decoder特征采样，应该让回归/分类与几何从开始共同适应；直接作用于老权重的掉点不能否定学习后的方案。短续训同时涉及LR/optimizer/EMA/增强状态，已关闭的12轮结果不适合作为新机制的因果基线。

这是最低可解释的三臂完整日程，不是最短试跑：单seed0、每臂120轮×304=36,480更新，三臂顺序执行。若预算无法接受，则本设计不执行；不暗改为12轮、不以历史A省略B0。

共同设置全部保持共同协议：train_core4869，逻辑batch16=物理8×2，768×1344，BF16 forward/FP32 loss，原GT/ignore、Hungarian和VFL/L1/GIoU权重；AdamW新状态、lr1e-4、warmup2000更新、cosine至1e-6，betas0.9/0.999，wd1e-4、norm/BN零wd，clip0.1。e1–117原强增强，e118–120原弱增强，不换采样/增强时钟。所有原可训练参数及BN train/running stats规则不变。

每臂由相同seed0原生head及同一ImageNet文件（SHA911a745b…fd720）独立初始化，先核对共用tensor和两项B1差异，再独立新建optimizer/EMA/RNG。EMA从本臂初始model完整拷贝，updates0，decay0.9999、warmups2000；每臂仅评价固定e120 EMA，不能选最佳epoch。GPU验收state不接正式训练。

推理为**单整图A式**，不加NMS，不复用C视图，不改变排序、top600/300及预算后raw-ignore/不补位。548只做固定终点评价，3臂×2预算=6组/12次双评价器；所有科学质量失败仍完成三臂终点。原A/C旧指标直接引用，并明确与新B0/P不是同轮训练因果比较。1602不访问。

## 5. 可否定条件、收益/保护及机制边界

建议在执行前按JSON冻结以下**新任务工程目标**，不是旧门槛修改、统计显著性或录用标准。对`P−B0`、`P−B1`分别按未舍入值全部判断：

|口径|门槛pp|
|---|---:|
|主top600 COCO AP75-small|≥+0.30|
|主top600 COCO APS|≥+0.20|
|主top600 COCO AP|≥0|
|主top600 APM、APL、AR-large|各≥−0.20|
|次top300 AP75-small|≥0|
|次top300 AP、APS|各≥−0.20|
|原主评价器AP，两档预算|各≥−0.20|

AP75-small优先于AP50，+0.30pp是相对现有约19.9%水平的实际目标；APS+0.20避免只修极少数定位而损伤总体小目标。保护0.20pp容忍小幅取舍，不证明无真实退化。原三seed SD不是本单seed的误差条，不能据此宣布显著。完整报告所有13项COCO与原评价器指标、P−B0、P−B1、B1−B0及P−原A/C，不用均值掩盖门槛。

若P只提升AP50/召回而AP75-small不达标，否定这套固定配方的高IoU实用预期。若P超过B0但不超过B1，不能证明span下限优于现成点数分配；本候选按门槛结束。中大保护或成本失败，也结束本固定方案，不调下限/点数重选。

机制的更强表述仍需谨慎：下限不保证不同双线性邻域，offset学习会补偿或收缩，参考本身并不等同GT大小。若未来获授权执行，在三臂每轮固定最后一个窗口的最后microbatch仅汇总已有forward中的最细层reference尺寸、点位置/stencil多样性及正常query匹配的小/中/大分组；不加forward、反向探针或中途AP。若小GT对应的reference几乎不触发下限，或有效stencil完全未变化，就不能用预期机制解释即使出现的AP收益。即使这些统计吻合，也只是支持性关联，三臂结果不能独证“采样集中是原A瓶颈”。
