# seed0大目标召回损失阶段：限定缓存诊断

2026-10-19。**结论：存在集中的高IoU NMS后失配，但本次固定反事实没有支持一个在原输出／评价限制下同时改善两个IoU的大目标干预；本轮不立项，关闭这一直接修复方向，不追加分析或自动候选。**

这不否定NMS存在局部替换损失，也不证明任何未来合并方法必定无效。可观测删除点已定位，
但“去掉该点就能得到可用改善”未成立。原C的全部结果、门槛与PASS保持，不重开Soft-NMS、
投票、微调、center等已关闭配方；本诊断不重新裁决论文贡献是否足够。

C在.75原全部query中53个large无合格几何框，另外2个经过每视图正确类候选选择后不可达，

实际只匹配968个。相比A原几何缺失77个，C的新增视图确实补了一部分几何机会，
随后又存在选择损失；不能说“C候选本来就全部没有”。
最终C无类最佳几何覆盖1000、正确类覆盖969、实际匹配968，三者不能互换。
最终正确类最大二分匹配上界也是968；在这一固定最终集合上，单纯换GT匹配顺序不能
恢复其余large。这是离线上界检查，不是新预测、可部署oracle或AP承诺。

同时兼顾其他尺寸：最终small的A/B/C匹配在.50为21344/20770/22636，.75为11283/10229/11613；
medium分别10401/10313/10535和8817/8534/8674。C的大目标保护问题不能由small收益掩盖，
也不能以large局部损失否认small实得增量。完整阶段、所有成对增减见[全部计数](STAGES.md)。

## 3 固定反事实否定“见到NMS损失便直接去NMS”

执行前固定B/C的NMS有无×600预算有无×class100有无八格，所有格都重新排序、raw-ignore、
完整匹配，不按GT选择预测，不扫NMS阈值、不评分AP。完整32行两分支两IoU在[反事实表](STAGES.md)。
重点对C：

|---|---|---|
|原规则|22636 /10535 /1044|11613 /8674 /968|
|只去NMS，保持600及class100|20383 /10036 /1015|12945 /8905 /973|
|只去600预算，保留NMS和class100|22856 /10622 /1046|11671 /8719 /969|
|只去class100，保留NMS和600|23032 /10574 /1044|11707 /8687 /968|

只去NMS在.75新恢复29、另丢24，净+5；.50恢复3、另丢32，净−29，并伴随small/medium退化。
因此43个NMS几何不可达不是“可无代价恢复43个TP”。不抑制时重复候选也参与排序和两层预算，
规则改变引发新的竞争；该离散反事实只显示交互，不能唯一分离分数校准、重复构成或几何质量。

去600预算的large净+2/+1确实为正，完整保留，不能写“所有反事实无效”；但是它既未对应
占主导的NMS损失，也改变指定输出600协议。去全部限制的上界更高，同样移除了原评价cap，
不是可同口径报分的干预。只去class100对large无增益。B只去NMS在.50净0、.75净+8，
也没有两个IoU同时净增。预注册“集中阶段＋相关规则在两个IoU净恢复”的工程筛选未得到
原预算／评价限制下的主NMS路径支持。**不把预算解除的少量正例藏起来，也不把改变评价
规则的有利上界偷换成可发表的修复。**
